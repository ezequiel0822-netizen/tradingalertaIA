# Memoria Automatica

Esta nota es el espacio donde Trading Alert AI puede guardar resumenes automaticos del sistema.

## Que guarda

- cantidad de candidatos analizados
- top candidatos del ciclo
- categoria: memecoin o bolsa
- score, confianza y subida estimada
- si se envio o no por Telegram

## Que NO guarda

- tokens reales
- chat IDs reales
- API keys
- seed phrases
- private keys
- passwords

## Regla de uso

La memoria sirve para recordar patrones, decisiones y comportamiento del bot. No reemplaza revision manual y no es recomendacion financiera.

## Estado inicial

- Version activa esperada: v2.6.0
- Funcion: resumen diario automatico + memoria de estado operativo
- Archivo generado por: Trading Alert AI
- Ubicacion configurada: `obsidian/tradingbot v.1`
